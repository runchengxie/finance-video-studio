# 第三方组件

根目录 MIT 许可只覆盖原创代码。依赖继续采用各自许可和说明，可在锁定的软件包中查看。

- `@fontsource/noto-sans-sc` 5.2.8 分发的 Noto Sans SC 采用 SIL Open Font License 1.1，版权属于 Google/Noto 贡献者。渲染从该包嵌入字体，不向 Google Fonts 请求资源。
- Playwright 采用 Apache-2.0，下载的 Chromium 另含其自身第三方许可。精确浏览器版本由锁定的 Playwright 包决定。
- FFmpeg 是外部程序，本仓库不分发。许可取决于所选构建，包含 libx264 的构建可能采用 GPL。
- csv-parse、Zod 采用 MIT；开发工具保留各自软件包中的许可。
- 文档使用 MkDocs、Material for MkDocs 和 mkdocs-static-i18n，分别保留其 BSD、MIT、MIT 许可及传递依赖说明。精确版本和哈希见文档依赖锁。文档使用本地主题资源和系统字体。

仓库不包含第三方视频、音频、行情或研究。示例数字和文字为本项目创建，没有打包语音录音。
