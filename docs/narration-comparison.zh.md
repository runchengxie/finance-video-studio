# 口播版本比较

使用绝对外部路径运行 `npm run studio -- compare BEFORE_MANIFEST AFTER_MANIFEST NEW_OUTPUT_DIRECTORY`。输出目录必须尚不存在。命令保留两份原文件，写出原始字节快照、`comparison.json` 和可阅读的 `index.html`。

比较对象是通过校验的项目清单和字幕文本。命令不会听音频、识别语音、核实实际说出的词句或事实，也不会授予审批或渲染视频。音频哈希仅来自清单声明，报告明确标记 `comparison: declared_only`、`verified: false`，不会读取音频文件。文字未变但音频哈希变化或缺失时，需要重新转写并人工试听审查。

报告按字幕序列对齐，避免插入或删除一句后将整段后文误报为修改。它列出新增、删除、文字修改、时间调整，以及新旧受影响场景、场景数字主张、发生变化的数字、日期、单位和财务词语。这些结果用于提示审查，不判断主张真假。时间使用各清单自己的帧率；时长来自项目时间线元数据，不代表实测音频时长。

序列对齐最多使用四百万个矩阵单元，超限时会在创建输出前拒绝比较。较大的稿件应拆分为便于审查的版本。命令不联网，也不读取无关工作区配置。
