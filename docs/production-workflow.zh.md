# 财经视频制作流程

[预检与完整交付](production-delivery.md)说明已实现的内容检查、内部笔记隔离和双封面打包命令。

真实项目按本页检查，并结合[渲染命令](production-rendering.md)和[稿件审阅要求](editorial-review.md)执行。这是制作指导，不代表 CLI 已自动执行所有检查。素材、研究记录和输出保存在所属项目的外部数据目录。

## 保留原件，确定时间轴

1. 保留原始音频、文稿和资料，记录 SHA-256、来源与使用权限。
2. 明确记录剪掉的片头、服务播报和片尾音乐，以实际采用的音频作为时间依据。调速、增益和替换配音分别留记录。
3. 原始转写与修订字幕分开保存。检查中文标点、财经术语、年份、单位和专名，逐条记录修订。多个识别模型结果一致，也不能证明原声说了什么。
4. 如实记录是否完成人工全片听校。用户同意保留读错的原声、修正字幕，不等于原声已经修复。

## 建立事实与数字记录

每个财经结论记录数值、单位、期间、主体、会计口径、带日期的来源和计算方法，区分实际结果、指引和估算。用内容资产增加额与负债变动推算现金付款时，保留公式和范围。不同公司的利润指标不能直接混排，合理解释也不能写成已经证实的因果。

影响结论的事实缺口应在批准前解决，或改成有依据的表述。把流程提示移出画面并不会解决事实问题。修订与未决问题留在项目记录中。

## 让画面跟随口播提供证据

| 口播内容 | 适合的画面 | 必要说明 |
| --- | --- | --- |
| 一个关键数字 | 随口播出现的数字卡 | 指标、单位、期间 |
| 两个数值或变化 | 对比柱、成对数字卡 | 可比口径、基期 |
| 多个期间 | 时间序列图 | 期间、刻度、缺失数据 |
| 现金、会计或业务机制 | 流程示意图 | 区分时点与因果 |
| 多个后续观察问题 | 分支图、思维导图 | 清晰层级与阅读顺序 |
| 业务背景 | 插图 | 生成概念图要作适当标识 |

维护关键数字的覆盖清单，关联口播时间、画面与来源。不能为了丰富图表编造观测值。只表示日期的年份可以作为标签，不必单独画图。数字卡出现时仍须保证字幕清晰。

## 动画以音频时间驱动

复用图表与示意图组件，通过确定性的 `drawAt(time)` 或同类接口定位画面。同一时间无论顺播、跳转还是倒退，都应得到相同状态。柱、线、箭头和分支逐步展开，统一缓动节奏，给最终数字足够阅读时间。装饰性的数字滚动不能看起来像真实的中间观测值。动态背景保持轻微，不干扰文字。

## 区分审阅界面与正式成片

**正式 MP4 默认只展示给观众看的内容。** “待听校”“原声保留”“年份按资料更正”“草稿”和审批状态等内部笔记，不烧进画面、字幕、标题卡或页脚，保存在审阅界面、修订记录和导出凭证中。

观众理解数据需要的来源、单位、期间、估算标识与重要限制继续保留。清理画面不能掩盖实质不确定性，也不能让人误以为事实已经全面核验。完整审阅版单独保留。正式版的 HTML、数据、素材和自定义导出适配器都应纳入具体快照的哈希批准。批准后修改呈现，应取得适用的新批准，不能绕过审阅直接渲染。

## 检查、导出与留存

- 按实际导出尺寸检查每条字幕、场景切换和数字事件，排查裁切、重叠和来源遮挡。覆盖场景边界，确认整个正式时间轴不出现内部提示。
- 检查动画起始、中间、完成状态和跳转恢复。按实际观看尺寸查看代表帧。
- 只渲染当前获批快照，输出到新目录，完成后再次核对批准与哈希，区分中间文件和成片。
- 完整解码 MP4，检查时长、帧数、尺寸、帧率、编解码器、音轨和色彩元数据。交付规格使用 BT.709 时，H.264 码流与容器都应核对。
- 留存成片 SHA-256、输入快照、剪辑范围、导出设置、检查结果及真实的人工听校状态。按交付需要附字幕、来源与修订记录。发布仍是单独的明确操作。

内置渲染器和项目自定义适配器可能支持不同格式。某次竖版成功导出，不代表内置 CLI 已支持该格式；应单独绑定并验证适配器。

## 有选择地吸收外部框架

[Remotion](https://github.com/remotion-dev/remotion) 可参考组件化视频与逐帧编排，采用前检查其[许可条款](https://www.remotion.dev/docs/license)。[Motion Canvas](https://github.com/motion-canvas/motion-canvas) 可参考解释类动画的代码组织。[faster-whisper](https://github.com/SYSTRAN/faster-whisper) 可辅助转写与词级时间定位，仍保留人工修订。

先吸收可复用组件、音频主时间轴、字幕与镜头映射、可定位动画及可重现验证这些方法。列出参考不等于已安装依赖或引入其代码。新引擎先用隔离的虚构示例试验，记录锁定版本、许可和运行成本，对比画质与导出可靠性后再决定迁移，不为增加框架数量更换现有流程。
